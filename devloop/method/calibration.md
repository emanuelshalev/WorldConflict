# Calibration with real signals

Real feedback (owner playtests, real users, support tickets, analytics) is stored as `real-signals/RS-NNN-*.md` with the verbatim words.

1. **Map** each statement to the archetype it resembles most.
2. **Replay**: would the panel have predicted it? Check the latest synthetic reports for the same build.
3. **Gap**: where the panel missed or contradicted it, name the attribute that caused it (patience, reading, priorities, deal-breakers, missing archetype).
4. **Correct** the persona(s): change attributes with evidence `observed / RS-NNN`; adjust weights; add an archetype if none matched.
5. **Hold-out**: keep one real statement aside and check the corrected panel finds it independently on the same build. This measures panel fidelity.
6. **Ledger**: flag past decisions that relied on the corrected attributes for review.

When a real customer contradicts the panel, go with the real customer.
