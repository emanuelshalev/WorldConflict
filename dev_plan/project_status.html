🌍 World Conflict — Project Status

Engagement overhaul · branch feat/engagement-overhaul · autonomous development log for owner review

Mission

Turn World Conflict from a working systems prototype into a game people finish, share and come back to: a geopolitical sim rooted in the real world of November 2026, playable in a 10–15 minute Flashpoint or a multi-day Campaign, beautiful on desktop and mobile, with optional LLM intelligence whose cost is always visible.

Pillars of the overhaul

⏱ Sessions that fit a life

Player picks a mode up front with an honest time estimate: Flashpoint (short, goal-driven, clear win/lose), Campaign (a full term, autosaved across days). Tuned with the headless harness.

🎢 Drama by design

Crisis cadence, escalation curves, near-loss moments and comeback mechanics measured by npm run sim — not left to chance.

🌐 The real world, today

Roster 25 → ~40 countries with current hotspots; a 2026 scenario with active wars; current leaders; flashpoints grounded in real events with "what really happened" debriefs.

🎨 Beautiful & intuitive

Keyless stylized map, situation-room visual identity, progressive onboarding, juicy feedback, shareable end card, mobile layout.

🤖 Three AI tiers

Algorithmic (free, offline) · LLM for key decisions · Full LLM. API key or local model; tokens & estimated cost shown live.

🧪 Expert & player feedback loop

Game-design, UX/visual and geopolitics experts plus four player personas review each milestone; findings feed the backlog.

Milestone log

System overview

Three layers: a pure deterministic engine, an agent layer (algorithmic or LLM), and a React client. The engine is the only source of truth; LLMs can propose but never mutate state directly.
