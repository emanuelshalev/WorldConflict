# World Conflict: intro script (80 s)

**Structure.** A cold open, then eight beats that each pair a REAL card with a GAME cut, then the title and CTA. The beats run in chronological order and build toward "now", November 2026. Facts come from `parallels.json`.

**Two visual languages.**
- **REAL cards** are typographic, like a wire-service bulletin. Use an off-white field (#F2EEE4), a near-black serif headline (Playfair Display, the Chronicle's face), a mono date line (IBM Plex Mono), and a thin rule. A small grey locator map (Natural Earth, public domain) carries one red map pin that drops in. Show no outlet names, logos or chyrons, no photos of people, and no casualty numbers.
- **GAME cuts** are real captures at 1920×1080 or 60 fps, recorded in the dark UI. Push in slowly on the element named; never fake UI.
- **Transition.** On each REAL-to-GAME change, the off-white card "inverts" to the dark UI: the pin becomes the matching country on the in-game map.

**Audio.** One low pulse (about 60 bpm) that rises through the beats. A typewriter or teleprinter tick on each REAL card, and a muted UI click on each GAME cut. Use no gunfire, explosions or sirens: the tension comes from the pulse and from silence.

## Production notes

- **Captures:** use `docs/images/*.jpg` for stills. For motion, record the real UI on each flashpoint at month 1, then play to the scripted month (card months are listed in `parallels.json`; for example, "The first shot" is month 9 for Taiwan). Hide the guest id and any localhost URL.
- **Map pins on REAL cards:** render from Natural Earth (public domain, no credit required; "Made with Natural Earth" is a courtesy). Don't use Google, Apple or Mapbox tiles.
- **Accuracy:** each REAL card's text must stay within the `realEvent` sentence in `parallels.json`. If a card is edited, recheck it. Never put a quote from a real person on a card.
- **Captions:** burn in the REAL card text, since it is already text. Provide an `.srt` for the taglines.
